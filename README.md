## wxWidget-based extra components
wxx : wxExtra

each extra component is a separate repo, added as a submodule here
1. [wxthings](https://github.com/externpro/wxthings) : a variety of data containers and controls
   * https://sourceforge.net/projects/wxcode/files/Components/wxThings/
   * mods to copied code https://github.com/externpro/wxthings/compare/v2006.04.28...dev
1. [wxplotctrl](https://github.com/externpro/wxplotctrl) : interactive xy data plotting widgets
   * https://sourceforge.net/projects/wxcode/files/Components/wxPlotCtrl/
   * mods to copied code https://github.com/externpro/wxplotctrl/compare/v2006.04.28...dev
1. [wxTLC](https://github.com/externpro/wxTLC) : a multi column tree control
   * https://sourceforge.net/projects/wxcode/files/Components/treelistctrl/
   * mods to copied code https://github.com/externpro/wxTLC/compare/v1208...dev
